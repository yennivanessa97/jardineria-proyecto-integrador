# Jardinería: proyecto integrador

Repositorio con todas las actividades de Bases de Datos II sobre la base de
datos Jardinería (MySQL), IU Digital de Antioquia.

**Autora:** Yenni Vanessa Delgado Velasco

| Carpeta | Contenido |
|---|---|
| `EA1_modelo_estrella/` | Diseño del modelo estrella del Data Mart |
| `EA2_staging/` | Base de datos Staging |
| `EA3_proceso_etl/` | Proceso ETL: informe, scripts y copias de seguridad |
| `pruebas_calidad_datos/` | Pruebas de calidad de datos y sus resultados |

Recorrido de los datos: `jardineria` (origen) → `jardineria_staging` →
`dm_jardineria` (Data Mart con modelo estrella).
